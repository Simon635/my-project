# Архитектура системы

## 1. Общая схема

Система состоит из трёх основных узлов:

```text
┌─────────────────────────────┐
│          Vue 3              │
│       localhost:5173        │
│                             │
│   Пользовательский клиент   │
└──────────────┬──────────────┘
               │
               │ HTTP
               │
               │ POST /api/repair-requests
               ▼
┌─────────────────────────────┐
│       ASP.NET Core          │
│       localhost:5000        │
│                             │
│        REST API             │
│   Проверка правил системы   │
└──────────────┬──────────────┘
               │
               │ SQL-запросы
               ▼
┌─────────────────────────────┐
│        PostgreSQL           │
│          :5432              │
│                             │
│       Хранение данных       │
└─────────────────────────────┘

архитектура web-ИС семестра
```

## 2. Назначение узлов

### Vue 3

Vue 3 является клиентской частью системы.

Клиент:

* отображает интерфейс;
* показывает список заявок;
* предоставляет форму создания заявки;
* отправляет HTTP-запросы к ASP.NET Core.

Порт разработки: `5173`.

### ASP.NET Core

ASP.NET Core является серверной частью системы.

Сервер:

* принимает HTTP-запросы;
* проверяет данные;
* проверяет права пользователей;
* выполняет бизнес-правила;
* изменяет заявки;
* обращается к PostgreSQL;
* возвращает результаты клиенту.

Порт разработки: `5000`.

### PostgreSQL

PostgreSQL используется для постоянного хранения данных системы.

В базе данных хранятся:

* заявки на ремонт;
* аудитории;
* пользователи;
* связи между ними.

Обычно используется порт `5432`.

## 3. Почему браузер не обращается к PostgreSQL напрямую

Vue не подключается к PostgreSQL напрямую.

Все запросы браузера проходят через ASP.NET Core. Сервер проверяет права пользователя и правила изменения заявки перед обращением к базе данных.

Например, при переводе заявки в работу сервер должен проверить, что текущий пользователь является назначенным исполнителем этой заявки.

Поэтому прямой стрелки:

```text
Vue → PostgreSQL
```

в архитектуре нет.

Есть только две связи:

```text
Vue → ASP.NET Core
ASP.NET Core → PostgreSQL
```

## 4. Пример взаимодействия

При создании заявки Vue отправляет серверу:

```http
POST /api/repair-requests
```

с JSON:

```json
{
  "title": "Не работает проектор",
  "classroomId": 312,
  "description": "Проектор не включается."
}
```

ASP.NET Core проверяет данные, создаёт заявку и сохраняет её в PostgreSQL.

После этого сервер возвращает результат Vue.
