## 4. Известные замечания

- При сборке backend выводится предупреждение NU1510 для Microsoft.Extensions.Identity.Core. На работу приложения не влияет.
- Порт API 5001 используется вместо 5000, поскольку 5000 занят системным сервисом macOS.
- Для создания заявки необходимо указывать существующий ID аудитории.

## 5. Итог

Основные проверки запуска, сборки, интеграции и сохранения данных пройдены. Результаты сквозного сценария и проверок безопасности подтверждены в предыдущих лабораторных работах.
