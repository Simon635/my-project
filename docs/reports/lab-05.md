# Лабораторная работа № 5

## Форма создания заявки и хранение данных в памяти

### Цель работы

Реализовать форму создания заявки с валидацией полей и добавлением записи в общий массив JavaScript без использования сервера и базы данных.

### Выполненная работа

- Реализована форма создания заявки.
- Добавлена проверка названия: от 5 до 80 символов.
- Добавлена проверка ID площадки: целое число больше нуля.
- Добавлена проверка описания: от 10 до 500 символов.
- Ошибки валидации отображаются возле полей формы.
- Новая заявка добавляется в общий массив со статусом `New`.
- После успешного создания форма очищается, приложение возвращается к списку.
- Использован `@submit.prevent` для предотвращения перезагрузки страницы при отправке формы.

### Результаты тестирования

| Проверка | Результат |
|---|---|
| Создание корректной заявки | Успешно: запись появилась в списке |
| Ввод названия `abc` | Успешно: запись не создана, отображается ошибка |
| Обновление страницы | Успешно: новая запись исчезла, исходные остались |

### Вывод

Форма создания заявки реализована и проверена. Данные хранятся в памяти приложения, поэтому после перезагрузки страницы новые записи исчезают. Это ожидаемо: сервера и базы данных пока нет.
