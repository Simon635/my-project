# Лабораторная работа № 6
## Клиент API, mock и состояния интерфейса

### Цель работы

Реализовать клиентский API-модуль Vue 3, имитацию ответов сервера и обработку состояний загрузки, пустого списка и ошибок.

### Выполненные работы

1. Добавлена настройка базового URL API через переменную окружения `VITE_API_BASE_URL`.
2. Добавлен файл `.env.example`; локальный `.env` исключён из Git.
3. Реализован mock для получения и создания заявок с задержкой около 500 мс.
4. Реализованы методы `getTickets()` и `createTicket(body)`.
5. Добавлена обработка ответов с кодами 400 и 500, а также ошибок соединения.
6. В список заявок добавлены состояния загрузки, пустого списка, данных и ошибки.
7. В форме создания заявки добавлены блокировка повторной отправки, индикатор «Создаём…» и отображение ошибок.

### Проверка

| Сценарий | Ожидаемый результат | Результат |
|---|---|---|
| Загрузка списка | Отображается список заявок | Пройдено |
| Создание корректной заявки | Заявка появляется в списке | Пройдено |
| Некорректные данные | HTTP-подобная ошибка 400, сообщение «Проверьте поля заявки» | Пройдено |
| Ошибка сервера | Ошибка 500, сообщение «Сервер не смог обработать запрос» | Пройдено |
| Нет соединения | Сообщение «Нет связи с сервером» | Пройдено |

### Примечание

Ошибки проверялись с использованием mock и переключения на настоящий `fetch`. Успешный реальный HTTP-запрос к серверу не проверялся, поскольку сервер API на порту 5000 не запускался.

### Вывод

В ходе лабораторной работы реализован клиентский API-модуль, добавлена имитация серверных ответов и обработка основных состояний интерфейса. Проверены ошибки валидации, сервера и соединения.
