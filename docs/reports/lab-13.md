## Результаты проверки

Обе части приложения успешно прошли сборку. Backend запустился и начал принимать запросы на порту 5001. Служебный маршрут `/health` вернул успешный ответ. Frontend успешно запустился на порту 5173.

Сквозной сценарий создания заявки диспетчером, назначения исполнителя и изменения статуса техником, а также проверка сохранения записи после перезапуска API были выполнены в лабораторной работе №12. Контрольная запись имеет ID 6, номер 1004 и статус InProgress.

Проверки разграничения доступа, кодов HTTP 401 и 403, хеширования паролей и безопасного отображения пользовательского ввода выполнялись в лабораторной работе №11.
