# Лабораторная работа №7
## Создание каркаса ASP.NET Core Web API

### 1. Цель работы

Создать серверное приложение ASP.NET Core Web API, настроить Swagger, служебные HTTP-маршруты и регистрацию сервисов через Dependency Injection.

### 2. Используемые технологии

- .NET SDK 10.0.105
- ASP.NET Core Web API
- Swashbuckle.AspNetCore 11.0.1
- C#
- Swagger UI

### 3. Создание проекта

В корне репозитория создан проект ASP.NET Core Web API в каталоге `backend`.

Проект использует целевую платформу .NET 10.0.

### 4. Настройка Swagger

Подключён пакет Swashbuckle.AspNetCore.

В конфигурации приложения зарегистрированы контроллеры, генератор Swagger и API Explorer.

Swagger UI доступен в режиме Development по адресу:

http://localhost:5000/swagger

### 5. Настройка порта

В файле `Properties/launchSettings.json` настроен HTTP-адрес:

http://localhost:5000

Для запуска используется среда Development.

### 6. Реализация служебных маршрутов

Добавлен маршрут GET `/health`.

Он возвращает HTTP 200 и строку `ok`, если приложение запущено и отвечает на запросы.

Добавлен маршрут GET `/info`.

Он возвращает JSON с названием приложения, текущей средой выполнения и версией лабораторной работы.

### 7. Создание сервисного слоя

Созданы каталоги:

- Controllers
- Services
- Models
- Data

В каталоге Services созданы интерфейс `IAppInfoService` и реализация `AppInfoService`.

Сервис предоставляет название приложения.

Регистрация сервиса выполнена через Dependency Injection с временем жизни Scoped.

Сервис внедряется в обработчик маршрута `/info`.

### 8. Проверка работоспособности

Выполнена сборка проекта командой `dotnet build`. Сборка завершилась успешно.

Запуск приложения выполнен командой `dotnet run`.

Проверка `/health` через curl вернула HTTP 200 и `ok`.

Проверка `/info` через curl вернула HTTP 200 и JSON с информацией о приложении.

Swagger UI успешно открылся по адресу `http://localhost:5000/swagger`.

### 9. Документация и Git

В README.md добавлена инструкция по запуску Backend, адрес Swagger и описание служебных маршрутов.

В `.gitignore` добавлены правила исключения каталогов `bin/` и `obj/`.

### 10. Результат работы

Создан и настроен базовый каркас ASP.NET Core Web API.

Реализованы служебные маршруты `/health` и `/info`, настроен Swagger и зарегистрирован сервис через Dependency Injection.

Создание заявок, CRUD-операции, подключение базы данных и интеграция с Vue в рамках данной лабораторной работы не выполнялись.
