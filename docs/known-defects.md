# Известные особенности и ограничения проекта

## 1. Использование порта API 5001

Стандартный порт 5000 оказался занят системным сервисом macOS (AirTunes). Для корректного запуска серверной части приложения используется порт 5001.

Адрес API: `http://localhost:5001`

Адрес клиентского приложения: `http://localhost:5173`

## 2. Предупреждение NuGet

При запуске backend присутствует предупреждение NU1510, связанное с пакетом `Microsoft.Extensions.Identity.Core`. Оно не препятствует сборке и запуску серверного приложения, работе API, авторизации и обработке заявок.

## 3. Указание аудитории при создании заявки

При создании заявки необходимо указывать существующий ID аудитории. В тестировании использовались аудитории 205, 210 и 215.

При указании несуществующей аудитории база данных отклоняет запись из-за ограничения внешнего ключа. Поэтому необходимо использовать ID, присутствующие в базе данных.

## 4. Особенности тестирования

Для проверки ролей используются отдельные учетные записи диспетчера и техника. Доступные действия определяются ролью авторизованного пользователя и назначением заявки.

При тестировании необходимо проверять не только отображение данных в интерфейсе, но и ответы API, а также фактические записи в PostgreSQL.
