# Матрица ролей и прав доступа

| Действие | Гость | Диспетчер | Техник |
|---|---|---|---|
| Просмотр заявок | Запрещено | Разрешено | Разрешено |
| Создание заявки | Запрещено | Разрешено | Запрещено |
| Назначение исполнителя | Запрещено | Разрешено | Запрещено |
| Изменение статуса заявки | Запрещено | Запрещено | Разрешено только для назначенной заявки |
| Просмотр отдельной заявки | Запрещено | Разрешено | Разрешено для авторизованного пользователя |

## Реализация контроля доступа

- Для аутентификации используется Cookie Authentication.
- Доступ к API ограничивается атрибутами Authorize.
- Для действий диспетчера используется проверка роли Dispatcher.
- Для изменения статуса используется проверка роли Technician.
- Техник может изменять статус только заявки, назначенной ему.
- При отсутствии авторизации сервер возвращает HTTP 401 Unauthorized.
- При отсутствии прав сервер возвращает HTTP 403 Forbidden.
- Пароли пользователей хранятся в виде хешей с использованием PasswordHasher.

## Результаты тестирования

| Сценарий | Ожидаемый результат | Фактический результат |
|---|---|---|
| Гость запрашивает список заявок | 401 | 401 |
| Гость создаёт заявку | 401 | 401 |
| Техник создаёт заявку | 403 | 403 |
| Диспетчер создаёт заявку | 201 | 201 |
| Диспетчер назначает техника | 200 | 200 |
| Техник изменяет назначенную ему заявку | 200 | 200 |
| Техник изменяет неназначенную заявку | 403 | 403 |
| Проверка хешей паролей | Пароли хешированы | HASHED |
| XSS-проверка описания заявки | Скрипт не исполняется | Успешно |
